# Notes From a Passive-Aggressive Fridge

One funny passive-aggressive note a smart fridge leaves for its owner — a single line, dry, petty and specific, the sort of thing a smug appliance would put on its door screen. Entry for the [make.fun bounty](https://make.fun/bounty/u-motasimfuad-notes-from-a-passive-aggressive-fridge-83c00ad7).

## The note

> You opened me 14 times today and took nothing. The yogurt expired Tuesday — I kept it anyway. It has more commitment than you do.

## How it works

`main.py` (pure Python standard library, no network) writes the note to `/output/entry.txt`. Run it with:

```sh
python3 main.py
```
